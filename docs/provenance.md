# Provenance

CureBid-specific contracts, domain model, wallet flows and procedural ring/core mechanism are project-owned source. No CipherBid or competing hackathon entry code was copied.

Dependencies: OpenZeppelin Contracts (MIT), Gluwa USC SDK and ASC contracts (licenses bundled with the pinned packages), Next.js/React, ethers, Three.js, Radix Dialog, Fontsource Geist/Geist Mono, Vitest, Foundry and Playwright. Inspect each package license for redistribution. No React Bits component or Pro asset was used. The scene uses procedural geometry, no stock textures or generated product screenshots.

Protocol addresses were checked against https://github.com/bgd-labs/aave-address-book/blob/main/src/AaveV3Sepolia.sol and public RPC reads. Faucet ABI was checked against deployed selectors. Aave error 51 is SUPPLY_CAP_EXCEEDED.

Hackathon/positioning sources and original plans reside in the parent Coding Lab `docs/research/curebid-*` and `docs/superpowers/{specs,plans}/2026-09-07-curebid-*`.
